# 特效镜头卡（模板）

> 单个镜头用一张卡。多镜头时在最前面加一行总览表，每张卡之间用 `---` 分隔。

## 1. {镜头名}

**一句话** {这个镜头在视觉上要发生什么} ｜ **类型** {能量系/物质系/形体系/空间系/时间系/生物腐蚀系/光学系} ｜ **时长** {5}s ｜ **画幅** {16:9}

### 冻结关键帧（首帧）

```text
{主体与姿态}，{发生源 + 特效当前形态（30% 蓄势态）}，{尺度参照物}，
{环境反馈：照亮了谁 / 投了什么影 / 什么被扰动}，
{景别}，{焦段}，{机位}，{景深}，
{主光方向 + 光比}，
{写实度 + 颗粒 + 画幅}
```

### 视频提示词

```text
【镜头】{机位}，{焦段}，{景别}，{主体占画面比例}
【时间轴】
0.0–{a}s｜起势：{一个可见变化}
{a}–{b}s｜爆发：{一个可见变化}
{b}–{c}s｜顶点：{一个可见变化}
{c}–{总时长}s｜余韵：{一个可见变化}
【运镜】{全片唯一的主动运镜，含速度；或「全程固定」}
【光照】{唯一主光源}，{亮度随什么变化}，{哪些物件的光斑必须同步}
【禁止】{具体禁止项 1}；{2}；{3}
```

### 设计说明

{为什么首帧停在这个状态、三层锚定分别落在哪句话、这个镜头最容易失败的点是什么}

## 填写提示

| 槽位 | 常见错误 | 正确做法 |
|---|---|---|
| 首帧状态 | 直接写顶点（满屏是光） | 停在 30% 蓄势态，把顶点留给视频 |
| 尺度参照 | 只说「巨大」 | 写「约人身高一半」「旁边立着一米高的栏杆」 |
| 环境反馈 | 只写光本身 | 至少写两处：照亮了谁、什么被推动了 |
| 节拍描述 | 一节拍写三件事 | 一节拍一个变化，跨节拍换维度（体量/亮度/位置/环境） |
| 运镜 | 「缓慢推进并环绕」 | 只留一种，或写「全程固定」 |
| 光照 | 「光线很美」 | 声明唯一光源 + 同步关系 |
| 设计说明 | 省略 | 必须写，用于后续返修时判断该改哪一层 |
