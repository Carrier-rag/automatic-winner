# 创意特效镜头设计

## 用途

把一个模糊的特效想法（「手心里聚一颗雷」「整面墙碎成粉末再重组」「时间静止只有主角能动」）变成可直接投喂生成模型的内容：

1. **冻结关键帧图片提示词** —— 用于生成首帧，作为整段视频的形态锚点
2. **分段时间轴视频提示词** —— 描述 0→N 秒内特效的微弧线、运镜、光照与禁止项
3. **（多镜头时）序列衔接方案** —— 跨镜头的形态锚点、光色、尺度换算

不做特效合成、不做后期调色、不绑定任何具体项目设定。

## 快速通道

需求已经明确（说了什么特效、多长、横竖屏）且只要一个镜头时，**直接跳到第 3、4 步出卡**，不要为了走完流程先讲一遍方法论。原则和分类库是给「需求含糊」和「结果不对」时用的，不是开工前的仪式。

## 两种产出模式

开工第一件事是分清要哪一种，规则差别很大：

| | **绿幕素材**（纯特效） | **实景成片镜头** |
|---|---|---|
| 背景 | 均匀纯绿 `#00B140`，无场景 | 具体场景，要写材质与光源 |
| 环境反馈（L3） | **必须没有**，特效不照亮背景 | 必须有，照亮/投影/扰动 |
| 尺度控制 | 画面占比 + 安全边距 | 画面内参照物 |
| 主色 | **避开绿、青绿**（会被抠掉） | 自由 |
| 景深 | 深景深，不虚化 | 常用于隔离主体 |
| 机位 | 正面平视 | 服务叙事 |
| 验收 | 能否一键抠干净 | 是否可信、有电影感 |

**默认取绿幕素材**——这个技能产出的多数是供后期合成的素材，不是成片。用户明确说「带场景」「在某某地方」「人物在旁边」时才用实景模式；两者都要时，先出绿幕版，再单独出实景版，不要混在一条提示词里。

绿幕模式的完整规则（色值、禁色板、边缘、构图、验收、抠像失败补救）见 `references/green-screen.md`，**开工前必读**。核心是五条：背景均匀纯色、特效不产生环境照明、不用绿色系主色、边缘无绿溢、用画面占比代替参照物。

## 核心原则

### 一、特效三层锚定

任何特效必须在提示词里同时交代三层，缺一层就会退化成「贴纸」：

| 层 | 回答的问题 | 缺失后的典型症状 |
|---|---|---|
| **L1 发生源** | 能量/物质从哪来？手掌、眼睛、地面裂缝、空中无源、还是消失中的身体 | 特效悬空漂浮，无因果 |
| **L2 形态与运动** | 什么形状、多大尺度、朝哪个方向、多快、生命周期几段 | 形态随机漂移、糊成一团 |
| **L3 环境反馈** | 照亮了什么、投了什么影、吹动了什么、留下什么痕迹 | 特效像贴图，不参与画面 |

L3 是最常被忽略、也是最能拉开质量差距的一层。自发光特效必须写「照亮了什么」，冲击类特效必须写「什么被推动了」。

**绿幕模式下 L3 必须归零**：背景不能被子照亮、不能有投影。此时 L3 改写为「特效自身的体积散射」，限定在特效轮廓内，不接触背景。这条是反物理的，但为了抠像必须这么做。

### 二、首帧即形态上限

生成模型极少能在片内创造出首帧没有的形态，只会让已有形态演化。因此：

- 若特效是**从无到有**（聚气、点燃、裂缝蔓延），首帧必须是「触发体已存在但特效未成形」的一瞬——手已抬起、指尖已有微光、地面已有一道细纹。首帧完全空白会导致片头几秒静止。
- 若特效是**已存在并爆发**，首帧应取「爆发前 0.2 秒的蓄势态」，把顶点留给视频。
- 不要把顶点放进首帧，否则整段视频只能衰退。

### 三、一段只有一个特效主动作

两个特效同时演进（一边爆炸一边变身）必然互相污染成糊状。需要复合时，改成**时间上前后衔接**，或把次要特效降级为环境层（背景余烬、空气扭曲）。

### 四、写物理，不写形容词

| 禁止 | 改写为 |
|---|---|
| 极其震撼的能量爆发 | 直径约 2 米的半球形冲击面从掌心垂直推出，边缘带白热滚边，前方空气产生可见折射 |
| 绚丽的魔法光效 | 冷青色体积光从指缝间溢出，照亮下颌与锁骨，墙面投出手影，随手指收拢而收缩 |
| 史诗级画面 | 低机位仰拍，人物占画面高度三分之一，天光被云层压暗，唯一光源是手中的光 |

模型的形容词理解力远不如物理描述。所有抽象词都翻译成**形状 + 尺寸 + 方向 + 速度 + 光的行为**。

### 五、尺度需要参照物

画面里必须有已知尺寸的东西（人、手、栏杆、树、楼、地砖），否则模型无法判断这是火花还是星爆。特效尺度用「约 X 米 / 约人身高一半 / 大于一辆车」这类可换算描述。

**绿幕模式没有参照物可用**，改用画面占比：写「特效主体占画面高度 70%，水平垂直居中，四周留出 ≥10% 安全边距」。占比是唯一的尺度锚点，安全边距还能防止后期裁切切到边缘。

## 画幅与竖屏

默认 16:9，但**先问一句是横屏还是竖屏**——竖屏的规则几乎和横屏相反。

| 项 | 16:9 横屏 | 9:16 竖屏 | 2.35:1 |
|---|---|---|---|
| 运动主轴 | 水平 | **垂直**（上下是主要运动方向） | 水平，强调横向延展 |
| 主体占高比 | 1/3–1/2 | **1/2–2/3** | 1/4–1/3 |
| 主光方向 | 侧光 / 侧逆光 | **顶光 / 上侧光**（上部是光源区） | 侧逆光，压暗两侧 |
| 横向扩散 | 安全，可满幅 | **极易出画**，须收敛或改为向上 | 适合横向，注意画幅窄 |
| 构图重心 | 三分法 | 中心垂直轴 | 中央横带 |
| 典型用途 | 宽银幕奇观 | 短剧、手机端 | 电影感 |

竖屏三条硬规则：

1. **别做横向炸开**。竖屏里「向两边扩散」是最本能的错误，宽高比会让特效瞬间出画。改成向上喷发、向下压、或沿中轴收束。
2. **上部留空间给光源和烟，下部留地面反光**，中间才是主体——竖屏是纵向叙事。
3. **特写要比横屏更紧**。宽度窄，手部动作容易出画，写的时候把「向前推」换成「向上抬」。

## 工作流程

### 第 1 步：补齐参数

需求缺项时按以下默认值补齐，并在输出里标注「默认」：

- **模式**：绿幕素材（纯特效，可抠像）
- 时长 5 秒（超过 8 秒必须拆成两段）
- 画幅 16:9（竖屏短剧用 9:16；绿幕素材建议先出 16:9，宽画幅裁切余地更大）
- 无人脸（独立创意素材默认不出现可识别面孔）
- 写实电影质感（非动画、非游戏 CG）

确需澄清时只问一句：**要不要带场景——纯绿幕特效，还是合成到实景里；竖屏还是横屏。**

### 第 2 步：分类

用决策树快速归位，别在七个类别之间纠结：

```
有形体、材料在变（烧/碎/融/烂）？ → 物质系
有机体、菌丝、触手、腐蚀？      → 生物腐蚀系
主体自身形态在变（变身/分身/变大）？→ 形体系
空间本身在变（门/扭曲/失重/领域）？ → 空间系
时间流速在变（静止/倒流/慢放）？   → 时间系
上面都不像，只是一团能量在聚散？   → 能量系
只是光、雾、雨、尘埃、镜头效果？   → 叠加层（挂在别的类上，不单独成镜）
```

确定类别后读 `references/vfx-taxonomy.md` 对应章节，取默认时间结构、关键词与高发失败点。

### 第 3 步：写冻结关键帧提示词

按 `references/prompt-patterns.md` 的「首帧模板」写。实景模式按此顺序：

```
主体与姿态 → 特效发生源与当前形态 → 尺度参照 → 环境反馈（光照/阴影/扰动）
→ 镜头（焦段、机位、景深） → 色彩与光比 → 质感与画幅
```

**绿幕模式换一套顺序**，把环境和光照全部删掉：

```
特效本体与发生源 → 形态与占比（占画面高度 X%，居中）→ 纯绿背景声明
→ 边缘与材质（无绿溢、边缘锐利）→ 镜头（正面平视、深景深、全画面清晰）
→ 主色（避开绿/青绿） → 禁项暗示（无场景、无投影、无渐变）
```

单条控制在 80–160 字。超过 200 字模型开始丢条件。

### 第 4 步：首帧验收

**出图之后、进视频之前，必过这一关。** 一张废图进视频等于烧掉整段算力。

实景模式六条硬指标：形态锁死、光源唯一、尺度可信、主体完整、环境参与、曝光有层次。

绿幕模式换成另一套判据：背景均匀无暗角、无场景元素、主色不含绿、边缘无绿边、背景未被照亮、居中且有安全边距。**最可靠的检查是把它丢进 Keylight 用默认吸管点一下背景，看能否一次抠干净。**

两套判据的完整清单见 `references/failure-modes.md` 第二节与 `references/green-screen.md` 第五节。

一票否决（重出图，不要将就）：主体肢体崩坏、光源方向自相矛盾、形态与描述完全不符；绿幕模式下再加一条——**背景有渐变或暗角**，这种图后期修不回来。

尚未出图时，把对应清单随交付一起给用户，作为他出图后的自检标准。

### 第 5 步：写分段时间轴视频提示词

按「视频模板」写。时间轴必须覆盖完整微弧线，四个节拍不可省：

```
起势（0–15%）→ 爆发（15–45%）→ 顶点（45–60%）→ 消退/余韵（60–100%）
```

每个节拍只写一个可见变化。运镜写一句（推 / 拉 / 摇 / 手持 / 固定），全片只允许一种主动运镜。

需要调力度或节奏时，用 `references/shot-sequence.md` 的强度三档 / 速度三档替换表，三处同步改。

### 第 6 步：提示词自检

过一遍 `references/failure-modes.md` 第一节清单。至少确认：

- L1/L2/L3 三层都写了（绿幕下 L3 改写为「不接触背景」）
- 首帧不是顶点
- 只一个主动作、一种主运镜
- 有尺度锚点（实景用参照物，绿幕用画面占比）
- 自发光写了照亮对象（绿幕下相反：写「不照亮背景」）
- 绿幕模式下主色不含绿、青绿
- 没出现抽象形容词

### 第 7 步：输出

用 `scripts/render_shot_card.py` 渲染成标准分镜卡，或按 `assets/shot-card-template.md` 手写。

- 单镜头：一张卡
- 多镜头：前附总览表，每个镜头一张卡，末尾补「跨镜头三不变量」小节

多镜头序列必读 `references/shot-sequence.md`，否则三个镜头剪在一起会像三个不同的特效。

输出用中文，提示词本体可按需夹杂英文术语（模型对材质与光学术语的英文响应通常更准，如 `volumetric light`、`caustics`、`subsurface scattering`）。

## 不适用范围

以下需求不属于这个技能，遇到时直接说明并换路径：

- **真人换脸、合成、抠像、跟踪** —— 后期合成问题，不是提示词能解决的
- **剪辑转场、节奏、字幕** —— 属于剪辑环节
- **布料 / 流体 / 破碎的物理解算** —— 需要三维软件
- **已有素材的调色与加光** —— 属于后期
- **叙事设计**（这个特效该不该出现、什么时候出现）—— 属于分镜或剧本
