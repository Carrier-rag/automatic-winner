# 创意特效镜头设计

## 用途

把一个模糊的特效想法（「手心里聚一颗雷」「整面墙碎成粉末再重组」「时间静止只有主角能动」）变成两段可直接投喂生成模型的内容：

1. **冻结关键帧图片提示词** —— 用于生成首帧，作为整段视频的形态锚点
2. **分段时间轴视频提示词** —— 描述 0→N 秒内特效的微弧线、运镜、光照与禁止项

不做特效合成、不做后期调色、不绑定任何具体项目设定。

## 核心原则

### 一、特效三层锚定

任何特效必须在提示词里同时交代三层，缺一层就会退化成「贴纸」：

| 层 | 回答的问题 | 缺失后的典型症状 |
|---|---|---|
| **L1 发生源** | 能量/物质从哪来？手掌、眼睛、地面裂缝、空中无源、还是消失中的身体 | 特效悬空漂浮，无因果 |
| **L2 形态与运动** | 什么形状、多大尺度、朝哪个方向、多快、生命周期几段 | 形态随机漂移、糊成一团 |
| **L3 环境反馈** | 照亮了什么、投了什么影、吹动了什么、留下什么痕迹 | 特效像贴图，不参与画面 |

L3 是最常被忽略、也是最能拉开质量差距的一层。自发光特效必须写「照亮了什么」，冲击类特效必须写「什么被推动了」。

### 二、首帧即形态上限

生成模型极少能在片内创造出首帧没有的形态，只会让已有形态演化。因此：

- 若特效是**从无到有**（聚气、点燃、裂缝蔓延），首帧必须是「触发体已存在但特效未成形」的一瞬——手已抬起、指尖已有微光、地面已有一道细纹。首帧完全空白会导致片头几秒静止。
- 若特效是**已存在并爆发**，首帧应取「爆发前 0.2 秒的蓄势态」，把顶点留给视频。
- 不要把顶点放进首帧，否则整段视频只能衰退。

### 三、一段只有一个特效主动作

两个特效同时演进（一边爆炸一边变身）必然互相污染成糊状。需要复合时，改成**时间上前后衔接**，或把次要特效降级为环境层（背景余烬、空气扭曲）。

### 四、写物理，不写形容词

| 禁止 | 改写为 |
|---|---|
| 极其震撼的能量爆发 | 直径约 2 米的半球形冲击面从掌心垂直推出，边缘带白热滚边，前方空气产生可见折射 |
| 绚丽的魔法光效 | 冷青色体积光从指缝间溢出，照亮下颌与锁骨，墙面投出手影，随手指收拢而收缩 |
| 史诗级画面 | 低机位仰拍，人物占画面高度三分之一，天光被云层压暗，唯一光源是手中的光 |

模型的形容词理解力远不如物理描述。所有抽象词都翻译成**形状 + 尺寸 + 方向 + 速度 + 光的行为**。

### 五、尺度需要参照物

画面里必须有已知尺寸的东西（人、手、栏杆、树、楼、地砖），否则模型无法判断这是火花还是星爆。特效尺度用「约 X 米 / 约人身高一半 / 大于一辆车」这类可换算描述。

## 工作流程

### 第 1 步：补齐参数

需求缺项时按以下默认值补齐，并在输出里标注「默认」：

- 时长 5 秒（超过 8 秒必须拆成两段）
- 画幅 16:9
- 无人脸（独立创意素材默认不出现可识别面孔）
- 写实电影质感（非动画、非游戏 CG）

确需澄清时只问一句：**这个特效是给什么题材用的、要不要出现人**。

### 第 2 步：分类与查库

读 `references/vfx-taxonomy.md`，把需求归入最接近的一类（能量系 / 物质系 / 形体系 / 空间系 / 时间系 / 生物腐蚀系 / 光学系）。分类决定三件事：默认时间结构、默认关键词、该类的高发失败点。

### 第 3 步：写冻结关键帧提示词

按 `references/prompt-patterns.md` 的「首帧模板」写。必须按此顺序：

```
主体与姿态 → 特效发生源与当前形态 → 尺度参照 → 环境反馈（光照/阴影/扰动）
→ 镜头（焦段、机位、景深） → 色彩与光比 → 质感与画幅
```

单条控制在 80–160 字。超过 200 字模型开始丢条件。

### 第 4 步：写分段时间轴视频提示词

按「视频模板」写。时间轴必须覆盖完整微弧线，四个节拍不可省：

```
起势（0–15%）→ 爆发（15–45%）→ 顶点（45–60%）→ 消退/余韵（60–100%）
```

每个节拍只写一个可见变化。运镜写一句（推 / 拉 / 摇 / 手持 / 固定），全片只允许一种主动运镜。

### 第 5 步：自检

过一遍 `references/failure-modes.md` 的检查清单。至少确认：

- L1/L2/L3 三层都写了
- 首帧不是顶点
- 只一个主动作、一种主运镜
- 有尺度参照
- 自发光写了照亮对象
- 没出现抽象形容词

### 第 6 步：输出

用 `scripts/render_shot_card.py` 渲染成标准分镜卡，或按 `assets/shot-card-template.md` 手写。多镜头时每个镜头一张卡，前附一行总览表。

输出用中文，提示词本体可按需夹杂英文术语（模型对材质与光学术语的英文响应通常更准，如 `volumetric light`、`caustics`、`subsurface scattering`）。
