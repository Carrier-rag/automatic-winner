# 绿幕特效素材

## 一、这是什么

只产出**特效本体**，背景为纯绿，用于后期抠像后合成到任何场景里。和「实景成片镜头」是两套完全不同的规则——很多在成片里成立的做法（环境反馈、投影、景深、参照物），在绿幕里全部要拆掉。

**判断标准**：这段素材能不能被 Keylight 一键抠干净，抠完边缘有没有绿边。能，就合格。

---

## 二、五条硬约束

### 1. 背景必须是均匀纯色

- 色值用广播绿 `#00B140` 或数字绿 `#00FF00`，提示词里写「均匀纯绿背景，chroma key green」
- **不能有渐变、暗角、纹理、颗粒不均**
- 不能用「绿色房间」「森林背景」——那是场景绿，不是色块绿

提示词写法：

```
背景为均匀纯绿的色块，无色差、无渐变、无暗角、无纹理。
```

### 2. 特效不能产生环境照明

这条是反物理的，但必须这么写。

真实情况下发光体一定会照亮背景，造成绿幕明暗不均，抠像就废了。所以：

- 不写「照亮墙面」「地面出现光斑」「投出手影」
- 改写为「特效自身发光，不对背景产生照明或投影」
- 如果需要体积光，只写「特效周围有自身的体积散射」，限定在特效轮廓内

### 3. 不用绿色系做主色

抠像原理是去除绿色通道，任何绿色成分都会被吃掉：

| 禁用 | 改用 |
|---|---|
| 绿色火焰、翠绿魔法、青绿色电弧 | 橙白火焰、紫色魔法、蓝白电弧 |
| 荧光绿、柠檬绿 | 品红、琥珀、冷白 |
| 含绿的青色（cyan-teal 偏绿） | 纯蓝青（偏蓝不偏绿） |

**安全色板**：橙、琥珀、白热、正红、品红、紫、蓝、冷白。

火、雷、光、冰都可以用这套色板，只是把原本的绿/青换掉。

### 4. 边缘要干净，不能有绿溢

绿幕上的发光体边缘容易被环境绿反染，抠完留一圈绿边（green spill）。

提示词要写：

```
边缘清晰锐利，无绿边溢出，无绿色反光沾染。
```

如果特效是半透明的（烟、雾、能量罩），绿溢会更严重——**优先避免半透明特效做绿幕**，或改成「边缘有实体感的不透明外壳」。

### 5. 用画面占比替代参照物

绿幕上没有可以换算的物件，所以「尺度需要参照物」这条不适用。改用**画面占比**锁定：

```
特效主体占画面高度的 70%，水平居中，四周留出不小于 10% 的安全边距。
```

占比 + 安全边距，是绿幕唯一可靠的尺度控制手段。安全边距还防止后期裁切或缩放时切到特效边缘。

---

## 三、构图规则

| 项 | 要求 | 原因 |
|---|---|---|
| 位置 | 居中（水平、垂直都居中） | 合成时自由度高 |
| 安全边距 | 四周 ≥10% | 防止裁切切边 |
| 景深 | 深景深，全画面清晰 | 虚化会破坏纯色均匀性 |
| 机位 | 正面平视 | 合成时透视才好匹配 |
| 倾斜 | 不倾斜、不旋转 | 后期可自行旋转 |
| 画面方向 | 特效运动**向上或沿中轴** | 横向运动会顶到边缘，抠像后不好裁 |

---

## 四、禁项池（绿幕专用）

必须挑 4–6 条写进「禁止」：

```
背景出现渐变、暗角或纹理
出现地面、地平线或任何场景元素
特效向背景投射阴影或照明
出现绿色或青绿色的发光
边缘出现绿色反光溢出
画面出现人物、手部或任何参照物
背景出现景深虚化
出现文字、水印、时间码
```

---

## 五、验收清单

出图/出片后逐项检查，**任一项不过就重做**：

- [ ] 背景是均匀纯绿，四角与中心的色值接近，没有暗角
- [ ] 没有任何场景元素（地面、墙、窗、道具）
- [ ] 特效主色不含绿、青绿
- [ ] 特效边缘锐利，放大看没有绿色描边
- [ ] 背景没有被特效照亮（没有光斑、没有投影）
- [ ] 特效居中，四周有安全边距
- [ ] 全画面清晰，背景没有虚化

抠像测试：把它丢进 Keylight 或达芬奇，用一个默认吸管点背景，看是否一次干净、边缘是否残留绿边。这一步比目视可靠。

## 六、抠像失败的三类原因与补救

| 现象 | 原因 | 补救 |
|---|---|---|
| 背景抠不干净，有斑块 | 背景有渐变或噪点 | 重生成，强调「均匀纯色、无色差」；应急可用 Luma Key 或 Roto |
| 特效边缘留绿边 | 绿溢 | 重生成，加「无绿边溢出」；后期用 spill suppression 压绿 |
| 特效主体被抠掉一部分 | 特效本身是绿色/青色 | 换色板重生成，这是唯一解 |

**不要试图靠后期修第一类和第三类**。绿幕素材的价值就在于省后期，返工成本远低于硬修。

---

## 七、和实景模式的区别（速查）

| 维度 | 实景成片镜头 | 绿幕素材 |
|---|---|---|
| 背景 | 具体场景，要写材质与光源 | 均匀纯绿，不写任何场景 |
| 环境反馈（L3） | 必须有，照亮/投影/扰动 | **必须没有** |
| 尺度控制 | 画面内参照物（人/栏杆/地砖） | 画面占比 + 安全边距 |
| 主色 | 自由 | 避开绿、青绿 |
| 景深 | 常用于隔离主体 | 深景深，不虚化 |
| 机位 | 可低可高，服务叙事 | 正面平视，服务合成 |
| 音效 | 需标注同步点 | 不需要，后期配 |
| 验收 | 是否有电影感、是否可信 | 是否能一键抠干净 |
