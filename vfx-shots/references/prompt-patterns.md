# 提示词模板与范例

## 一、首帧模板（冻结关键帧）

按固定顺序填七个槽位。顺序不能乱——模型对靠前的词权重更高，主体与发生源必须在前。

```
{主体与姿态}，{发生源 + 特效当前形态}，{尺度参照}，
{环境反馈：照亮了谁 / 投了什么影 / 什么被扰动}，
{镜头：景别 + 焦段 + 机位 + 景深}，
{色彩与光比：主光方向 + 光比数值}，
{质感：写实度 + 颗粒 + 画幅}
```

### 槽位填写要点

| 槽位 | 必写 | 禁止 |
|---|---|---|
| 主体与姿态 | 具体肢体位置（摊开的右手、半跪的膝盖） | 「一个人」这类无信息量描述 |
| 发生源 | 特效从哪里出来，以及当前到了哪一步 | 直接写顶点状态 |
| 尺度参照 | 可换算的已知物体 | 只说「巨大」「极小」 |
| 环境反馈 | 至少两个受影响的物件 | 只写光本身 |
| 镜头 | 景别 + 焦段 + 机位高低 + 景深 | 一次写两种运镜 |
| 色彩 | 主光方向 + 光比（如 8:1） | 「好看的颜色」 |
| 质感 | 写实/实拍感 + 颗粒 + 画幅 | 「8K 超高清」这类无效堆砌 |

### 焦段与景别速查

| 想要的效果 | 焦段 | 景别 | 景深 |
|---|---|---|---|
| 特效压迫感、主体巨大 | 24–35mm | 低机位仰拍全景 | 深 |
| 特效与人等量对话 | 50mm | 中景 | 中 |
| 细节质感、微观奇观 | 85–100mm 微距 | 特写 | 浅 |
| 空间扭曲、环境变形 | 14–21mm | 广角全景 | 深 |
| 隔离感、黑背景 | 85mm | 中近景 | 极浅 |

### 快门语言

模型对快门速度有响应，写进去能显著改善质感：

- 高速粒子、水花、碎片 → `高速摄影，快门 1/2000，颗粒锐利`
- 火焰、烟、能量流动 → `常速，快门 1/60，边缘柔和拖尾`
- 时间静止 → `快门 1/4000，所有悬停物绝对锐利无抖动`
- 慢动作 → `慢动作拍摄，120fps 降格，运动呈现清晰拖尾`

## 二、视频模板（分段时间轴）

```
【镜头】{机位 + 焦段 + 景别 + 主体占比}
【时间轴】
0.0–X.Xs｜起势：{一个可见变化}
X.X–X.Xs｜爆发：{一个可见变化}
X.X–X.Xs｜顶点：{一个可见变化}
X.X–X.Xs｜余韵：{一个可见变化}
【运镜】{全片唯一的主动运镜，含速度}
【光照】{光源是谁，随什么变化，必须同步的对象}
【禁止】{3–5 条明确的负向约束}
```

### 写作规则

1. **每个节拍一个变化**。写两个变化，模型只会执行其中一个，通常是后一个。
2. **节拍里写「什么被改变」而不只是「特效在做什么」**。环境反应比特效本身更能让画面成立。
3. **运镜只写一种**。推和摇同时写必然冲突。可以在固定机位里写「微推」这种弱运动。
4. **光照必须写「同步」**。声明特效亮度变化时哪些物件的光斑要跟着变，是压制闪烁最有效的手段。
5. **禁止项要具体**。「不要出现人脸」有效，「不要崩坏」无效。

### 常用禁止项池

按需挑 3–5 条，不要全抄：

```
不出现可识别的人脸 / 不出现文字与水印 / 镜头不抖动不漂移 /
特效形态不变成烟雾 / 背景不出现额外光源 / 主体服装不发生变化 /
不出现肢体变形与多余手指 / 画面不出现慢动作回放 / 色彩不整体偏色
```

## 三、完整范例

### 范例一：掌心雷（能量系 · 5 秒 · 16:9）

**首帧提示词**

> 一只摊开的右手悬在胸前、掌心朝上，掌中央悬浮着一颗直径约三厘米的青白色光核，光核表面有细密电弧沿切线游走，光线从指缝间漏出、照亮掌心皮肤下的血管与袖口内侧的织纹，手腕处的布料被上升气流轻微掀起。中景，50mm，浅景深，背景是压暗的潮湿石室墙面。冷青主光，环境近乎无光，光比约 8:1。电影级写实质感，轻微胶片颗粒，16:9。

**视频提示词**

> 【镜头】固定机位，50mm，浅景深，主体占画面高度二分之一。
> 【时间轴】
> 0.0–0.8s｜起势：光核体积缓慢收缩，电弧密度上升，掌心皮肤被照亮，指缝漏光增强。
> 0.8–2.2s｜爆发：光核骤然扩张至拳头大小，青白色电弧向四周炸开约半米，袖口与发丝被气流掀起，石墙上出现跳动的光斑。
> 2.2–3.0s｜顶点：能量密度最高，中心接近过曝，边缘有蓝白色溢光，空气产生可见热扰动，细小尘粒被推离手掌。
> 3.0–5.0s｜余韵：光团缓慢收束回光核，电弧变稀疏，墙面光斑随之衰减，余辉在手掌皮肤上停留后消失。
> 【运镜】全程固定，仅在 0.8–2.2s 之间以每秒约三厘米的速度向前微推。
> 【光照】唯一光源是掌心光核，亮度随能量强度变化，墙面与衣袖上的光斑必须同步跳动。
> 【禁止】出现人脸；镜头抖动；特效形态变成烟雾；背景出现其他光源。

**为什么这样写**：首帧只给到 30% 聚能态，把爆发留给视频；三处环境反馈（照亮血管、掀起布料、墙面光斑）让特效参与画面；`【光照】` 里的「同步」是防闪烁的关键。

### 范例二：石墙崩解（物质系 · 5 秒 · 16:9）

**首帧提示词**

> 一面约三米高的粗糙花岗岩墙占据画面大部分，墙面中央有一道从地面向上延伸的蛛网状裂纹，最宽处约两指，缝内有细粉缓缓渗出并沿墙面滑落，裂缝周围的石块表面浮尘被震起。画面右侧立着一根高约一米的金属栏杆作为尺度参照。低机位，35mm，深景深。正午侧逆光，光从左上打入，裂缝深处呈黑影。写实质感，16:9。

**视频提示词**

> 【镜头】低机位固定，35mm，深景深，墙体占画面三分之二。
> 【时间轴】
> 0.0–1.2s｜起势：裂纹以每秒约二十厘米向上蔓延并分叉，粉尘持续从缝中渗出，栏杆上的浮尘被震落。
> 1.2–2.8s｜扩展：墙体中央开始鼓起并出现块状分离，最大石块约半米，边缘松动后向外倾斜，粉尘增厚成薄雾。
> 2.8–3.6s｜顶点：整片墙体在中部塌落，碎石向下加速坠落砸地并弹起，粉雾瞬间膨胀充满画面下半部，栏杆被碎石击中轻微晃动。
> 3.6–5.0s｜沉降：粉尘缓慢下沉并逐渐变稀，碎石堆静置在地面，空中残留的细粉在侧逆光中形成可见光柱。
> 【运镜】全程固定，不推不摇。
> 【光照】侧逆光方向不变，粉雾浓时画面整体变灰、对比下降，雾散后恢复。
> 【禁止】镜头抖动；出现人影；碎石向上飞；粉尘呈均匀一片。

**为什么这样写**：碎裂强制走「裂纹 → 块状分离 → 塌落 → 沉降」四段，跳过任何一段都会被模型简化成「溶解」；栏杆作为尺度参照同时承担了「被击中晃动」的环境反馈。

### 范例三：时间静止（时间系 · 5 秒 · 16:9）

**首帧提示词**

> 一块约四十厘米宽的玻璃窗在画面中央炸裂，数百片碎片呈放射状悬停在半空，每片碎片边缘锋利并反着天光，碎片间距保持均匀，最近的一片距镜头约半米。空气中悬浮着静止的玻璃粉末。一只戴黑色手套的手从画面右侧伸入，指尖距最大的一片碎片约十厘米。中景，85mm，浅景深，背景街景虚化为灰蓝色。冷调自然光从窗外逆射，碎片边缘形成细亮轮廓光。写实，16:9。

**视频提示词**

> 【镜头】固定机位，85mm，浅景深，手与碎片占据画面中部。
> 【时间轴】
> 0.0–1.0s｜起势：所有碎片绝对静止、无任何位移与抖动，只有手套的手指继续向前移动，指尖接近碎片。
> 1.0–2.0s｜反转：手指轻触最大碎片，碎片被推离原位并缓慢旋转移开，周围碎片纹丝不动，静止与运动形成强对比。
> 2.0–4.0s｜主体行动：手穿过碎片间的空隙向前伸出，途经碎片被气流带动轻微偏移但仍近乎静止，手套织物随动作产生褶皱。
> 4.0–5.0s｜恢复：所有碎片在同一瞬间恢复运动，沿原轨迹继续飞散并向下坠落，玻璃粉末重新飘动。
> 【运镜】全程固定，85mm 定焦，无推拉。
> 【光照】窗外逆光恒定，碎片旋转时轮廓光位置随之变化，其余部分亮度不变。
> 【禁止】碎片出现抖动或漂移；出现慢动作回放；出现人脸；碎片恢复后倒流。

**为什么这样写**：时间静止的成立完全依赖对比，所以首帧就把「炸裂的动能」冻结在半空，全片唯一能动的是手套；「绝对静止、无抖动」是必须明写的，否则模型会给所有碎片加微小飘动。

## 四、术语对照

需要更强材质/光学表现时，可在中文提示词后附英文术语，通常对模型更有效：

| 中文 | 英文 |
|---|---|
| 体积光 / 丁达尔效应 | volumetric light / tyndall effect |
| 溢光 | bloom |
| 热扰动 | heat haze |
| 次表面散射 | subsurface scattering |
| 焦散 | caustics |
| 运动模糊 | motion blur |
| 轮廓光 | rim light |
| 各向异性高光 | anisotropic highlight |
| 悬停微粒 | suspended particles |
| 过曝滚降 | overexposure rolloff |
