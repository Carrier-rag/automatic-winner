# 失败模式与自检

## 一、投喂前自检清单

逐项打勾，任一项不通过就先改提示词再生成，不要靠多抽卡赌。

**结构层**

- [ ] L1 发生源写清楚了（特效从哪来）
- [ ] L2 形态锁定了一个明确形状词（球/锥/环/柱/网状）
- [ ] L3 至少写了两处环境反馈
- [ ] 有可换算的尺度参照物
- [ ] 首帧不是顶点状态
- [ ] 全片只有一个特效主动作
- [ ] 全片只有一种主动运镜

**时间层**

- [ ] 四个节拍齐全，且每个节拍只写一个变化
- [ ] 节拍时间之和等于视频时长
- [ ] 有「消退/余韵」段，不是停在顶点

**光照层**

- [ ] 声明了唯一主光源
- [ ] 自发光特效写了照亮对象
- [ ] 写了「光斑/亮度必须同步」的对象
- [ ] 光学效果方向与主光一致

**语言层**

- [ ] 没有「震撼、炫酷、史诗、绚丽」等抽象词
- [ ] 没有同时出现两种运镜
- [ ] 禁止项 3–5 条且具体

## 二、症状 → 病因 → 修法

### A. 形态类

| 症状 | 病因 | 修法 |
|---|---|---|
| 特效糊成一团烟雾 | 没锁形状词，模型默认往烟走 | 加死形状词：`半球形` `锥形` `环状` `柱状`，并加禁止项「形态不变成烟雾」 |
| 特效形态每帧都在变 | 只描述了「能量」没描述边界 | 写边界特征：`边缘呈锯齿状白热滚边` `表面有持续旋转的纹路`，边界比内部更容易被锁定 |
| 特效像贴纸，不参与画面 | L3 环境反馈缺失 | 补：照亮了哪个物件的哪个面、投了什么影、什么被吹动 |
| 尺度忽大忽小 | 无参照物 | 画面内放入手/人/栏杆/地砖，并把特效尺寸写成「约 X 米 / 约人身高一半」 |
| 特效悬空无来源 | L1 缺失 | 明确写出发生源：掌心、指尖、眼睛、地面裂缝、水面、口中 |

### B. 运动类

| 症状 | 病因 | 修法 |
|---|---|---|
| 前两秒像静止图 | 首帧太空，或起势段没写变化 | 首帧加入已存在的触发体；起势段写一个微小但可见的变化（体积收缩、裂纹延长） |
| 全片只有一个状态 | 时间轴塌陷，节拍写了但没变化 | 每个节拍强制换一个维度：体量变 / 亮度变 / 位置变 / 环境反应变 |
| 顶点出现过早 | 首帧给了顶点 | 首帧回退到 30% 状态，顶点留在 45–60% |
| 主体自己漂移 | 没写主体固定 | 加「主体位置与姿态在全程保持不变，仅 XX 变化」 |
| 两个动作打架 | 一段写了两个主动作 | 拆成两段视频，或把次要动作降级为环境层 |
| 碎片/粒子向上飞 | 没写重力 | 加「向下加速坠落，受重力驱动」 |
| 时间静止物体仍在抖 | 没写绝对静止 | 加「绝对静止，无位移、无抖动、无漂浮」 |

### C. 一致类

| 症状 | 病因 | 修法 |
|---|---|---|
| 首帧与视频形态不匹配 | 两段提示词用了不同描述 | 视频提示词的第一句必须复述首帧的形态与位置 |
| 服装/发型中途变了 | 未约束 | 加禁止项「服装与发型全程不变」，并在时间轴里不提衣服变化 |
| 背景凭空多出东西 | 禁止项缺失 | 加「背景元素不新增、不消失」 |
| 肢体变形、多出手指 | 手部参与特效时高发 | 减少手部特写时长；加禁止项「不出现多余手指与肢体变形」；必要时改用剪影 |
| 整体颜色漂移 | 未锁色彩 | 明确主色 + 光比，加「全程色调一致，不整体偏色」 |

### D. 光照类

| 症状 | 病因 | 修法 |
|---|---|---|
| 画面亮度忽明忽暗地闪 | 未声明同步关系 | 在【光照】里写「X 的亮度随 Y 同步变化」，并指定不参与变化的区域 |
| 特效亮但环境不变 | 只写了发光没写照亮 | 补「照亮了墙面的左半边」「地面出现跳动的光斑」 |
| 特效发灰发暗 | 缺少过曝表现 | 加「中心接近过曝，边缘有蓝白色溢光」 |
| 光斑方向与主光矛盾 | 多处光源 | 全片只留一个光源，其余全部删掉 |

### E. 质感类

| 症状 | 病因 | 修法 |
|---|---|---|
| 像游戏 CG 不像实拍 | 缺材质细节 | 加「轻微胶片颗粒」「镜头轻微脏污与色散」「实拍质感」 |
| 特效边缘太干净 | 缺不规则性 | 加「边缘不规则、有断续与拖尾」 |
| 有机体像塑料 | 缺湿润与次表面散射 | 加「湿润反光」「半透明，光从背面透出」 |
| 粉尘/烟雾太均匀 | 缺密度层次 | 加「密度不均，局部浓局部透光」 |

## 三、返修优先级

生成结果不满意时，按以下顺序改，不要一次全改（全改会失去归因能力）：

1. **先改首帧** —— 80% 的形态问题源于首帧，首帧对了视频才可能对。
2. **再改时间轴节拍** —— 结构问题（塌陷、过早到顶点）在这里修。
3. **最后加禁止项** —— 禁止项是补丁不是方案，堆多了会削弱正向描述。

每轮只改一处，改完重新生成对比。

## 四、什么时候该拆镜

出现下列任一情况，不要继续调提示词，直接拆成两段：

- 特效形态需要在片内发生**质变**（如水 → 冰 → 蒸汽）
- 复合了两类以上特效
- 时长超过 8 秒
- 需要同时展示「宏观体量」与「微观细节」

拆镜后每段各有一个首帧，用剪辑衔接。拆镜的成本远低于反复抽卡。
