# 特效分类库

按「特效靠什么驱动」分类，而不是按外观分类。因为同一种外观可以由完全不同的物理来源产生，而物理来源才决定提示词该怎么写。

每类给出：形态库、默认时间结构、关键词、高发易错点、首帧建议。

---

## 一、能量系

**驱动**：无形能量（电、光、力场、声波、引力）的聚集、释放、塑形。

### 形态库

- **聚集态**：光点 → 丝状电弧 → 旋转旋涡 → 致密球体
- **释放态**：半球冲击面、锥形喷射、环形冲击波、贯穿光束、扇形散射
- **持续态**：包裹主体的护罩、沿肢体流动的能量纹、悬浮的悬浮环

### 默认时间结构（5 秒）

| 节拍 | 时间 | 内容 |
|---|---|---|
| 起势 | 0–0.8s | 能量从发生源渗出，体积小、颜色冷、周围空气开始轻颤 |
| 爆发 | 0.8–2.2s | 形态迅速扩张，亮度上升，环境开始被照亮、被推动 |
| 顶点 | 2.2–3.0s | 最亮最密，出现溢光与过曝边缘，尘埃/碎屑被推开 |
| 余韵 | 3.0–5.0s | 主体收束或散逸，余辉附着在环境上慢慢衰减 |

### 关键词

`volumetric light` `bloom` `lens flare` `electric arc` `plasma` `shockwave` `rim light` `overexposure rolloff` `heat haze` `air distortion`

### 高发易错点

1. **没有照亮环境** —— 最致命。必须写「照亮了 X 的哪一面」。
2. 能量形态每帧都在变 —— 必须锁定形状词（球形/锥形/环状），否则模型自由发挥成烟雾。
3. 顶点过早 —— 首帧就满屏是光，视频只能变暗。
4. 忘记空气扰动 —— 加 `heat haze`、`visible refraction` 能立刻提升真实感。

### 首帧建议

取「聚集到 30%」的状态：源点已亮，能量尚未成形，环境已被微微照亮。

## 二、物质系

**驱动**：实体材料的变化——燃烧、熔化、碎裂、蒸发、凝固、流体。

### 形态库

- **火**：舌状火焰、回旋火球、贴地流淌的火、爆燃云
- **碎**：蛛网裂纹 → 块状崩解 → 细粉雾化（三阶段不可跳）
- **流体**：水柱、水幕、溅射王冠状、粘稠拉丝
- **烟尘**：翻滚团块、贴地推进的尘墙、垂直烟柱
- **相变**：金属熔滴、石面白霜蔓延、玻璃结晶化

### 默认时间结构

物质系比能量系**慢半拍**，起势要更长：

起势 0–1.2s（裂缝出现 / 火星点燃）→ 扩展 1.2–2.8s → 顶点 2.8–3.6s（最大体量或完全崩解）→ 沉降 3.6–5.0s（余烬、粉尘缓缓落下）

### 关键词

`embers` `soot` `molten` `viscous` `debris` `dust cloud` `crack propagation` `shatter` `smolder` `ash fall` `gravity driven`

### 高发易错点

1. **碎裂跳阶段** —— 直接从完整变粉末，缺少中间块状崩解，看着像溶解不像碎。
2. 火没有热扰动 —— 火焰上方必须有空气扭曲与飘动的余烬。
3. 碎屑不受重力 —— 必须写「向下加速坠落」。
4. 烟尘太干净 —— 真实烟尘有明暗层次，写 `uneven density`。

### 首帧建议

取「破坏已开始但主体完整」：能看到第一道裂纹 / 第一簇火苗，主体仍然可辨识。

## 三、形体系

**驱动**：主体自身形态改变——变身、分身、巨大化、液化、透明化、机械化。

### 形态库

- **变身**：表面材质剥落 → 内部新形态透出 → 外壳碎散
- **分身**：主体拉出残影 → 残影固化为实体 → 本体与原体难以区分
- **巨大化**：骨骼/轮廓先撑起衣物 → 尺度参照被打破（旁边的东西变小）
- **液化**：边缘开始下垂 → 整体失去支撑 → 重组成新形状

### 默认时间结构

形态系依赖**参照物变化**来传达，因此需要两个镜头或至少画面内的对比物：

起势 0–1.0s（表面异常）→ 转变 1.0–3.2s（材质/尺度重构）→ 定型 3.2–4.2s（新形态稳定）→ 余波 4.2–5.0s

### 关键词

`transformation` `morph` `peeling surface` `residual afterimage` `silhouette shift` `scale reference` `material transition` `reforming`

### 高发易错点

1. **尺度没有参照** —— 巨大化必须让已知物体在画面里显得变小，否则观众看不出变大了。
2. 变身过程中主体面目全非 —— 至少保留一个识别特征（发型、肩线、伤疤）贯穿全程，否则会像换了个人。
3. 残影太实或太虚 —— 残影需要写「半透明、边缘有运动模糊」。
4. 衣物不参与变化 —— 变身时服装必须同步响应，否则是最明显的破绽。

### 首帧建议

取「异常已出现、形态未变」：皮肤上已有一道裂开的质感，或轮廓边缘已开始轻微流动。

## 四、空间系

**驱动**：空间本身被改变——传送门、扭曲、折叠、失重、领域展开。

### 形态库

- **传送门**：边缘不规则撕裂 → 内部是另一处景象 → 边缘持续放电/渗出光
- **扭曲**：背景被透镜化拉伸、直线变弯、边缘有重复折射
- **失重**：所有碎屑/液滴悬停并缓慢旋转，头发与衣物向上飘
- **领域**：地面蔓延出纹路 → 边界升起半透明墙 → 内部规则改变（雨停、火不燃）

### 默认时间结构

空间系最强的是**边界扩张**，所以时间结构围绕边界：

起势 0–1.0s（出现一个点/一条线）→ 扩张 1.0–3.0s（边界蔓延，内部可见）→ 稳定 3.0–4.0s（边界完整，内部景象清晰）→ 持续/收束 4.0–5.0s

### 关键词

`portal` `spatial distortion` `lens warping` `fractured edge` `zero gravity` `floating debris` `domain boundary` `ripple in air`

### 高发易错点

1. **门内门外的光照不互通** —— 传送门必须有光从内部溢出照亮门框周围。
2. 扭曲被做成「滤镜」 —— 必须是**局部**扭曲，画面其他区域保持锐利，否则像整张图被拉伸。
3. 失重只写主体 —— 失重感来自环境（尘埃、水珠、布料、纸片全部上浮）。
4. 边界没有材质 —— 领域墙必须有可见的质感（薄膜、雾面、光栅）。

### 首帧建议

取「边界刚撕开一道缝」：裂缝里透出不属于当前场景的光。

## 五、时间系

**驱动**：时间流速被改变——静止、倒流、慢动作、加速、循环。

### 形态库

- **静止**：所有飞溅物悬停成雕塑状，只有目标主体移动
- **倒流**：碎屑反向聚合、水向上落、烟回缩、火焰倒燃
- **慢动作**：高速物体呈现清晰拖尾，液滴变形过程可见
- **循环**：同一动作重复，接缝处有细微错位

### 默认时间结构

时间系的关键是**建立对比**，因此必须在前 1 秒内让观众看出「谁不受影响」：

起势 0–1.0s（事件正在高速发生）→ 反转 1.0–2.0s（时间突然改变，对比成立）
→ 主体行动 2.0–4.0s（唯一能动者完成动作）→ 恢复 4.0–5.0s（时间回流，悬停物同时落下）

### 关键词

`frozen in mid air` `suspended droplets` `reverse motion` `time remapping` `high speed photography` `1/2000 shutter` `motion trail` `unaffected subject`

### 高发易错点

1. **没有对比就没有时间感** —— 必须同时存在「静止的」和「运动的」，只写静止会变成一张图。
2. 静止物有轻微抖动 —— 必须写 `perfectly still, no drift`。
3. 倒流没有因果关系 —— 倒流要有明确的「回到某个起点」，否则像随机倒放。
4. 慢动作只写慢 —— 慢动作的质感来自细节：变形、飞溅、形变恢复。

### 首帧建议

取「事件已发生到一半并被冻结」：碎玻璃停在半空、水花凝固在最高点。

## 六、生物腐蚀系

**驱动**：有机体、菌丝、触手、腐蚀、寄生、生长。

### 形态库

- **生长**：藤蔓/菌丝沿表面蔓延，末端卷曲，接触点有渗液
- **触手**：从液体/暗处升起，表面有湿润反光与吸盘细节
- **腐蚀**：材质先失去光泽 → 起泡 → 剥落 → 露出底层
- **寄生**：细丝钻入皮肤，沿血管走向扩散，皮下可见蠕动

### 默认时间结构

有机生长是**非线性加速**的，起势慢、后段快：

起势 0–1.5s（一个芽点/一处霉斑）→ 蔓延 1.5–3.2s（加速扩散，出现分支）→ 覆盖 3.2–4.2s → 蠕动/呼吸 4.2–5.0s（静止但有生命感）

### 关键词

`mycelium` `tendril` `wet sheen` `subsurface scattering` `organic growth` `creeping` `pustule` `undulating` `capillary spread`

### 高发易错点

1. **太干净** —— 生物组织必须有湿润反光、半透明次表面散射，否则像塑料模型。
2. 生长是匀速的 —— 真实有机生长需要「慢-快-停」的节奏。
3. 腐蚀跳阶段 —— 光泽→起泡→剥落三段，缺一段就像贴图。
4. 触手末端没有细节 —— 末端卷曲与吸盘是可信度的关键。

### 首帧建议

取「第一个接触点已出现」：一个湿润的小点、一道细丝、一小块失去光泽的区域。

## 七、叠加层（大气与镜头光学）

> **注意定位**：这一类和前六类不同，它**不是独立的特效**，而是一层可以挂在任何特效上的质感层。它不单独成镜、不承担叙事、不设自己的节拍。
>
> 用法：先定前六类中的主类，再把这里的元素当作环境层叠加上去。写「火焰」时叠「热浪」，写「传送门」时叠「体积光与尘粒」。
>
> 只有当需求本身就是纯氛围（一束光穿过窗户、雨夜的路灯）时，它才作为唯一内容出现——此时按下面的独立时间结构处理。

**驱动**：镜头与大气本身的效果——光柱、雾、雨、尘埃、反射、色差。

### 形态库

- **光柱**：丁达尔效应、穿过窗/树冠的体积光、尘粒在光中浮动
- **大气**：贴地雾、烟幕、热浪、水汽
- **反射**：水面倒影、湿地面、玻璃多重反射、金属各向异性高光
- **镜头**：光斑、星芒、色散、暗角、轻微脏污

### 默认时间结构

叠加层通常作为**环境层**贯穿全片，不设独立节拍，而是叠加在别的特效上做质感提升。单独使用时：

渐强 0–2.0s → 峰值 2.0–3.5s → 渐弱 3.5–5.0s

### 关键词

`tyndall effect` `god rays` `volumetric fog` `dust motes` `caustics` `anamorphic flare` `chromatic aberration` `wet reflection` `light shaft`

### 高发易错点

1. **体积光没有遮挡物** —— 光柱必须由窗框、树枝、烟雾切割出来，否则是一团白雾。
2. 灰尘分布均匀 —— 真实尘埃有疏密，写 `uneven density`。
3. 光斑方向与主光不一致 —— 所有光学效果必须服从同一光源方向。
4. 滥用镜头光斑 —— 一个镜头最多一处。

### 首帧建议

任意，但必须明确主光方向，后续所有层都服从它。

## 复合特效的处理

需求跨两类时（如「火焰中有传送门」），按以下优先级处理：

1. **定主类**：哪一类承担叙事功能，它的时间结构说了算。
2. **次要类降级为环境层**：只写形态与光照，不写它的时间演进。
3. **仍不够就拆镜**：一段视频一个主类，用剪辑衔接。
